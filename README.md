# Проект автоматизации тестирования сервиса Яндекс Самокат.
Данный проект содержит автотесты для проверки API учебного сервиса Яндекс Самокат. Тестирование реализовано с использованием фреймворка Pytest и паттерна проектирования API Object Model, что позволяет разделить логику тестов и реализацию HTTP-запросов.

## Быстрый старт (Запуск тестов)
Для запуска тестов и просмотра отчета в браузере выполните:
```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск тестов (результаты автоматически сохранятся в папку allure-results)
pytest

# 3. Генерация и открытие отчета Allure в браузере
allure serve allure-results
```

## Стек технологий 

* **Python** — язык разработки
* **Pytest** — фреймворк для написания и запуска тестов
* **Requests** — библиотека для отправки HTTP-запросов
* **Allure Framework** — генерация детальных и наглядных отчетов о тестировании

## Покрытие тест-кейсов
* **Курьеры (test_courier.py):**
    * **Создание курьера:**
        * **Позитивные сценарии:**
            * Успешная регистрация нового курьера с полным набором валидных данных.
            * Создание курьера без необязательного поля `firstName`.
        * **Негативные сценарии:**
            * Валидация ошибки при попытке создания дубликата (повторный запрос с тем же логином).
            * Валидация ошибки при отсутствии обоих обязательных полей 
            * Валидация ошибки при отсутствии одного из обязательных полей.
            * Валидация ошибки при передаче обоих обязательных полей пустыми.
            * Валидация ошибки при передаче одного из обязательных полей пустыми.
    * **Авторизация курьера:**
        * **Позитивные сценарии:**
            * Успешный вход с валидными данными.
        * **Негативные сценарии:**
            * Ошибка авторизации при отсутствии обязательных полей в теле запроса.
            * Ошибка авторизации при передаче пустых значений в полях `login` или `password`.
            * Ошибка авторизации при вводе несуществующего логина.
            * Ошибка авторизации при вводе неверного пароля.
            * Ошибка авторизации при данных несуществующего пользователя.

* **Заказы (test_order.py):**
    * **Создание заказа (параметризованные тесты):**
        * **Позитивные сценарии:**
            * Проверка создания заказа с выбором только одного цвета (`BLACK` или `GREY`).
            * Проверка создания заказа при выборе обоих доступных цветов сразу.
            * Проверка создания заказа без указания цвета (пустой список цветов).
            * Проверка создания заказа при полном отсутствии ключа `color`.
    * **Список заказов:**
        * **Позитивные сценарии:**
            * Успешное получение списка существующих заказов.

## Установка
1. **Клонировать репозиторий**
```
git clone https://github.com/ctyal/qa_python_sprint_7.git
cd qa_python_sprint_7
```

2. **Создать виртуальное окружение и активировать его**
```bash
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
venv\Scripts\activate     # Для Windows
```

3. **Установить зависимости**
```bash
pip install -r requirements.txt
```

4. **Установить и настроить Allure для отчетов**
Инструкции доступны в [документации Allure Report](https://allurereport.org/docs/).

## Запуск тестов
Все базовые флаги (-v и --alluredir=allure-results) уже настроены в pytest.ini.
**Запуск всех тестов с автоматической записью отчета в allure-results/**
```bash
pytest
```

**Запуск тестов по маркерам**
```bash
pytest -m positive   # Только позитивные тест-кейсы
pytest -m negative   # Только негативные тест-кейсы
```

**Просмотр отчета в браузере**
```bash
allure serve allure-results
```
